## Requirements

- Python 3.10+
- NumPy, SciPy, pandas, matplotlib, scikit-learn (practicals 1–21, 23–25)
- TensorFlow/Keras (practical 22)

```bash
pip install numpy scipy pandas matplotlib scikit-learn tensorflow
```

## Run

```bash
python practical_01_matrix_operations.py
```

Run any file similarly, e.g. `python practical_26_dynamic_pricing.py`.
